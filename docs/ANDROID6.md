# 安卓 6.0 车机说明

安卓 6.0（API 23）的车机是 OpenHC 支持的最低版本。这个系统的车机能不能用 OpenHC，取决于**车机系统自己**有没有
留下两样东西：数据线连接要的 VPN 授权，无线连接要的本地热点接口。授权正常由系统授权页给；授权页被裁掉的车机上，
OpenHC 还有一条自己完成授权的路（见下文，要特定的签名）。这条路也走不通、热点接口又没有时，OpenHC 在这台车机上
投不了屏——这不是安装包或者设置的问题，改界面也变不出来。

## 先看这台车机用得了哪种连接方式

打开 OpenHC →「设置」，如果车机系统太老或缺少授权页，设置页最上面会多出「这台车机」一组，写着：

| 这一栏 | 写着「可以」 | 写着别的 |
|---|---|---|
| 数据线连接 | 有 VPN 授权页、或 OpenHC 能自己完成授权，插线能用 | 原因（例如「没有 VPN 授权页」），数据线连接开通不了 |
| 无线连接 | 热点、蓝牙、车机蓝牙地址都齐全 | 原因（例如「这个安卓版本开不了本地热点」） |

首页顶上如果出现「这台车机用不了 OpenHC」，说明两种方式都用不了。

## 数据线连接：为什么需要 VPN 授权页

数据线连接时，手机被切成 USB 网卡，OpenHC 要在车机上建一块**只给本应用用**的虚拟网卡（TUN），手机才能按网卡方式
和车机通信。普通应用要建这块网卡，只有经过系统的 `VpnService` 一条路，而系统只把这条路交给**用户在系统授权页上同意过**
的应用——这是安卓的设计，不需要 root、也不需要 ADB 就能用，前提是系统里得有那个授权页
（例外：拿得到系统免确认授权权限的应用不用授权页，见下面「还能做什么」第 2 条）。

授权页是系统自带的组件（`com.android.vpndialogs`）。一些车厂在裁剪系统时把它整个删掉了：这时
`VpnService.prepare()` 仍然会返回一个「去授权」的 Intent，但拉起时什么都不发生，或者直接报错。

OpenHC 0.2.8 起会先查系统里有没有这个组件：

- 没有：首页有线那一栏直接写「这台车机不能用 VPN，无法有线连接：系统里没有 VPN 授权页」，不再给「去授权」按钮
  （点了也没用）；诊断日志里也会记一行「系统里有 VPN 授权页：否」。
  例外：OpenHC 拿得到系统免确认授权的权限（用平台同一把测试密钥签名的变体）时不提示、不变栏，
  点「开始」时自己把授权办妥，直接连。
- 有：和以前一样，点「开始」时弹出系统的 VPN 授权框。

### 还能做什么

1. **先确认系统里真的没有**。有的车机把授权页藏在别处（例如「设置 → 更多连接 → VPN」里打开一个 VPN 应用时才弹），
   也有的车机出厂时冻结了这个组件。可以在车机的应用管理里找 `com.android.vpndialogs` 或「VPN」这个系统应用：
   能找到但被停用的，启用它，重启车机后再打开 OpenHC 看「设置 → 这台车机」里数据线连接是不是「可以」。
2. **用平台测试密钥签名的 OpenHC**（适合系统整包就是用 AOSP 公开测试密钥签的车机）：系统用哪把密钥当平台密钥，
   用同一把密钥签名的应用就拿到签名级权限，其中包括**免用户确认的 VPN 授权**。OpenHC 用这把密钥签出来后，
   在没有授权页的车机上会自己把授权办妥——不用授权页、不用 ADB、也不用 root，车主什么都不用做。
   怎么核对车机、怎么出这种包，见 [`tools/platform-key`](../tools/platform-key/README.md) 的说明。
   普通签名拿不到那个权限，这条路不会触发；正常出厂的车机也用不着它（授权页都在）。
   注意这类系统本身对谁都敞开着平台签名，安全上不要指望它。
3. **换用无线**（要安卓 8.0 及以上，见下）。
4. 车机系统可以被改（能刷机、有系统权限）的话，把系统的 `com.android.vpndialogs` 装回去；这属于改动车机系统，
   不在 OpenHC 的范围里，OpenHC 也不会提供做这件事的工具。
5. 用别人维护的、专门适配老车机的版本（见 README 的「常见问题」第 1 条）。

> ADB 能用的车机上，`adb shell appops set io.github.gcbond.openhc ACTIVATE_VPN allow` 也能把授权写进系统
> （效果一样）。连不了 ADB 的车机就走上面第 2 条：它不依赖任何外部工具。

> OpenHC 不需要 root、ADB 或系统签名，也不打算为了绕开授权页引入这几种做法：那种改动能用一次，但每次开机、
> 每次换车机都要重新折腾，而且很容易被车厂的系统更新弄坏。

## 无线连接：安卓 8.0 起才有本地热点

无线连接时车机要开一个本地热点给手机连。让应用自己开热点的系统接口（`WifiManager.startLocalOnlyHotspot`）
**安卓 8.0（API 26）才有**，安卓 6.0 的车机上没有它，无线连接也就用不了。这一条和应用里的写法无关。

安卓 6.0 车机上「无线连接」点「开始」会提示热点接口不支持；设置页「这台车机」一栏也会写清楚。

## 「蓝牙好像也不行」

和 VPN 授权页无关。蓝牙在安卓 6.0 上是**安装即授予的普通权限**，OpenHC 的清单里已经声明了
（`BLUETOOTH`、`BLUETOOTH_ADMIN`），不存在要用户点的「附近设备」权限——那个权限安卓 12 起才有。

安卓 6.0 车机上蓝牙出问题，按下面的顺序看：

1. **先在设置页看「这台车机 → 无线连接」**：如果写着「这个安卓版本开不了本地热点」，那蓝牙本身没问题，
   真正的原因是无线连接在这台车机上根本用不到（安卓 8.0 起才有）。这种情况下蓝牙功能不会有人调用。
2. **车机蓝牙开着没有**：无线连接要求蓝牙打开。首页无线那一栏的提示会说要打开蓝牙。
3. **读不到车机蓝牙地址**：OpenHC 从系统属性 `persist.sys.bt_addr` 读车机自己的蓝牙地址（二维码里手机拿它直接连车机）。
   有的老车机没有这个属性，这时页面会提示，请在「设置 → 连接方式 → 车机蓝牙地址」里手动填写（格式 `AA:BB:CC:DD:EE:FF`，
   用手机上的蓝牙扫描类应用可以查到车机的地址）。
4. **一开监听就失败（Error -1、-7）**：见 README「常见问题」第 6 条，多半是车机蓝牙不归安卓系统管，或者被别的互联应用占着。
5. **要看具体的错**：在「设置 → 诊断 → 导出诊断日志」，日志里有无线连接每一步的说明和错误原因
   （不含蓝牙地址和密码，地址只留首尾几位）。

## 诊断

「设置 → 诊断 → 导出诊断日志」的开头摘要里有几行专门用来看这种情况：

- `系统里有 VPN 授权页：是/否`
- `VPN 授权：已授权 / 等用户在系统框里同意 / 没有授权页（拿得到免确认授权的权限时会说开始连接时会自己补）`
- `系统读得到车机蓝牙地址：是/否`
- `无线缺的权限：……`

报告问题时把这几点和车机型号、安卓版本一起附上，就能判断是车机系统缺东西，还是 OpenHC 的问题。
